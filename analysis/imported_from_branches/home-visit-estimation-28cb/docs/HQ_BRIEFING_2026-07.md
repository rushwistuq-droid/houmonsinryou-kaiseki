# わかさクリニックグループ  
# 訪問診療・地域需要推計 成果資料（2026年7月）

**目的**: クリニック住所から半径圏の居宅訪問診療需要を公的統計で推計し、実績と突合して本部判断に使う。  
**対象**: 13院（本院〜浦和）  
**標準半径**: **8 km**（5km=コア、10km=広域補助）  
**リポジトリ成果物**: `home_visit_demand/`

---

## 1. いま何ができるか

| 機能 | 内容 |
|------|------|
| 高精度需要推計 | 国勢調査メッシュ人口 × 都道府県別NDB受療率 × 施設実在座標 |
| 実績突合 | 施設/居宅の実数と市場規模・獲得率を比較 |
| 圏域重複除去 | グループ院の8km圏をメッシュ単位でユニオン／排他化 |
| 外部競合 | 関東信越厚生局の**在宅療養支援診療所（在支診）**件数 |
| 期待獲得率帯 | 密度・グループ近接・在支診密度から妥当シェア帯を提示 |
| アクションシート | 院別に「やる／様子見／横展開」とKPIを固定 |
| 主担当マップ | 三鷹クラスターのメッシュ最寄り院割当 |
| 浦和トラッキング | 3/6/12か月の獲得率軌跡（分母固定） |
| ダッシュボード | 定例用の単一HTML |

## 2. 指標の定義（読み方の固定）

| 指標 | 意味 | 使い方 |
|------|------|--------|
| **居宅市場規模** | 半径圏に発生しうる居宅訪問診療需要（他院含む） | ポテンシャルの母数 |
| **居宅獲得率** | 自院実績居宅 ÷ 居宅市場規模 | 競争力・進捗 |
| **ユニオン市場** | グループ圏域の重複を1回だけ計上した需要 | グループ全体のポテンシャル |
| **排他的居宅市場** | 当該院が最寄りメッシュの需要 | 重複圏での院別KPI母数 |
| **在支診** | 厚生局届出の在宅療養支援診療所（座標突合済） | 外部競合の主指標 |
| **施設契約KPI** | 自院が契約・担当する施設の実績患者 | 施設評価（市場シェアは使わない） |

> 推計値は「自院が取れる人数」ではなく「地域の市場規模」です。  
> 自院の取れ高は **獲得率** で見ます。

### 読み方のポイント
- 東京圏の獲得率が数%でも、在支診が数百院ある超稠密圏では **期待帯内** になりうる。
- 本院・津田沼は期待帯を大きく上回り、**成功型の横展開候補**。
- 市川は帯を下回るため、居宅開拓が優先。

## 6. 半径の運用ルール（正式）

| 半径 | 位置づけ | 用途 |
|------|----------|------|
| **8 km** | 標準（必須） | 院間比較・定例・期待帯 |
| **5 km** | コア | 立ち上げ・強い獲得の再現範囲 |
| **10 km** | 広域補助 | 出店・広域需要（獲得率は参考） |

- 院間比較は必ず同一半径。
- 短期目標の母数に10km市場は使わない。
- 参考: 本院の5km獲得率は **53.9%**（コアが非常に強い）。

---

## 7. 施設の扱い

- 施設は **契約患者数** と **パネル内構成比** で評価する。
- 施設市場需要との「シェア」は使わない（契約施設≠圏内全施設需要のため）。
- パネル施設比率が概ね70%超（本院・所沢・石神井・ひばり 等）は、居宅新規の下限設定を推奨。

## 12. 本部への推奨メッセージ（1枚）

1. **市場はユニオン、院KPIは排他＋獲得率**で見る。  
2. **標準半径は8km**。本院・津田沼の強さは5kmコアでも確認。  
3. **市川は居宅開拓**、**浦和は立ち上がり軌跡**、**三鷹クラスターは主担当分担**。  
4. **施設は契約KPI**。市場シェアで施設を評価しない。  
5. 外部競合は名称近似ではなく **厚生局在支診** を使う。
