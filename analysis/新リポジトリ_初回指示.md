## 状況別の追加指示

### A. 経営資料だけ欲しい場合

```
analysis/artifacts/ の PDF と analysis/わかさ_居宅患者目標_成果資料.md を読み、

コード変更は不要です。
```

### B. 1院だけ深掘りしたい場合

```
PYTHONPATH=home_care_target/src:home_visit_demand/src \
  python3 -m home_care_target.cli --clinic ひばりが丘

上記出力をベースに、北多摩北部（東久留米・清瀬・西東京）の開拓戦略を
analysis/北多摩北部3市_居宅開拓比較.md と突合して更新してください。
```

### C. 実績を更新したい場合

```
analysis/confidential/wakasa_patient_actuals.yaml の as_of と各院人数を更新し、
python3 -m home_care_target.cli --dashboard --write-outputs
python3 home_care_target/scripts/compare_actuals.py
を実行して、actuals_vs_acquisition_public.json を再生成してください。
```

### D. 新機能（例: 四半期レポート自動化）を追加したい場合

```

実装は承認後。
```
