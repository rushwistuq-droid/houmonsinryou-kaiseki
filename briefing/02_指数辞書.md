## 2. 主要指数の定義（詳細）

### 2.1 顕在居宅需要（旧称: 居宅市場規模）
- **意味**: 診療圏（半径6km。2026-10-09 までは8km）に住む高齢者のうち、地元県の受療率どおりに訪問診療（居宅）を受けている人数の推計。自院が取れる人数ではなく地域全体の規模。
- **式**: 250mメッシュ高齢者（2020国勢調査→2025社人研で補正）× 都道府県・年齢別の居宅受療率（NDB）。施設由来分は入居系施設の定員から差し引く（系統Bの式をそのまま使用）。
- **変更点**: 系統Bは圏内で最も人口の多い県の受療率を圏全体に当てていた。県境の院（本院・所沢・市川など）で値が跳ねるため、**メッシュごとに所在県の受療率**を当てるよう修正した。

### 2.2 潜在居宅需要・未充足度
- **潜在居宅需要**: 同じ高齢者に**東京都の受療率**を当てた場合の居宅需要。
- **未充足度** ＝ 潜在 ÷ 顕在。東京都内はほぼ1.0、神奈川は約1.5、埼玉・千葉は約2.0〜2.4。
- **なぜ東京基準か**: 東京都の居宅受療率は埼玉の約2.2倍。高齢者の状態に大差はなく、差の多くは「訪問診療の供給がまだ追いついていない」ことによると考えられる。都内水準は、首都圏で実際に達成されている普及度の上限目安になる。
- **注意**: NDBは医療機関所在地ベースの算定回数を含むため、県境付近では都内の医療機関が埼玉・千葉の患者を診ている分が都側に計上される。それでも「埼玉・千葉はまだ取られていない需要が厚い」という向きは変わらない。

### 2.3 実効競合ユニット・競合密度
- 厚生局届出名簿（2026-06）の在支診・在支病を、**機能強化型（支援診1・2、支援病1・2）=1.0、従来型（支援診3）=0.35、在支病はさらに県別の病院訪問ウェイト**（訪問件数/施設の病院÷診療所）で重み付け。わかさ・元気会は除外。
- 名簿は2026-08-01版。座標は医療情報ネット突合→JMAP点データ突合→国土地理院の住所検索の順で全件に付与（取れない場合は県ごとに割り戻す補正が働く）。
- **競合密度** ＝ 実効競合 ÷ 75歳以上人口 × 1万。

### 2.4 年数・地域補正後の実力（パフォーマンス指数）
- **式**: 実績居宅患者 ÷ 獲得予測モデルの期待値（同じ開院月数・同じ未充足度・同じ開院時期の院なら何人になるはずか）。
- **期待値は「その院を除いた残りの院で作った式」で出す**（2026-10-09 変更）。自院を含めて式を作ると式が自院に寄り、好調な院は低め・不調な院は高めに出るため。
- **読み方**: 1.0＝期待どおり。**1.15以上を「期待を上回る」、0.85以下を「期待を下回る」**とし、その間は差がないものとして扱う。
- 本部が「努力不足」と評価する前に、まずこの指数で地域・年数の影響を除いて比べる。

### 2.5 到達目安・上位院比（2026-10-06 改訂）
- **取り込み率** ＝ 居宅患者 ÷ 自院が最寄りとなる潜在居宅需要。
- **地域タイプ**: 未充足度1.2以上＝未充足型（埼玉・千葉の郊外、所沢・津田沼・市川・浦和）、未満＝都市型。
- **上位院の取り込み率**: 在宅開始24か月以上の院のうち、同じ地域タイプで取り込み率の上位2院の平均。都市型 約5%、未充足型 約10%（半径6km。院名は機密版）。
- **本院は除外**: 地域で最初に訪問診療を始めた先行者で、地域で確立した地位による取り込み率は他院の目安にならない（上位院の約3.3倍）。
- **到達目安** ＝ 自院が最寄りの潜在居宅需要 × 上位院の取り込み率。**上位院比** ＝ 実績 ÷ 到達目安。
- **読み方**: 停滞していて上位院比が80%以上 → 自院の担当エリアは取り切りつつあり、エリアの狭さ（他院との重複）が制約。80%未満で停滞 → エリア内に余地があり、紹介経路などの獲得の仕組みが課題。
- **限界**: 上位院も伸び続けているので100%は上限ではなく「いまの上位水準」。未充足型は比較できる院が2院しかない。
- **改訂の経緯**: 当初は本院の浸透率を全院の基準にしていたが、本院は先行者で他院に当てはまらないとの指摘を受けて改めた。

### 2.6 獲得予測モデル
```
log(居宅患者) = a + b·log(在宅開始後月数) + c·log(未充足度) + d·[施設重視期に開院]
  b = 0.72   … 月数が2倍になると居宅は約1.6倍
  c = 1.42   … 未充足度2.0の地域は1.0の地域の約2.7倍
  d = -0.61  … 施設重視期に開院した院は約46%少ない
  決定係数 R² = 0.88、1院ずつ抜いて予測した誤差 ±29%（半径6km）（11院。浦和＝開院直後、本院＝先行者は除外）
```
係数・精度は `briefing/output/growth_model.json`、他の候補との比較は `briefing/output/index_screening.csv`（03 参照）。

### 2.7 新規・終了の指数（2026-10-08 追加。院内の月次記録から）
- **月間新規**・**月間終了**: その月内に始まった／終わった患者数（居宅・施設別）。直近12か月の平均を使う（季節の偏りをならす）。
- **終了率** ＝ 月間終了 ÷ 患者数（月あたり）。**平均在籍月数** ≒ 1 ÷ 終了率。
- **均衡患者数** ＝ 月間新規 ÷ 終了率。終了は患者数にほぼ比例するため、新規が今のペースのままなら患者数はこの水準に向かって落ち着く（約1〜2年で近づく）。**均衡／現在** が1.15以上＝まだ伸びる、0.9〜1.15＝横ばい（均衡に到達）、0.9未満＝縮小方向。
- **新規の強さ** ＝ 到達目安（2.5）100人あたりの月間新規。担当エリアの大きさで割った新規の量で、上位4院の平均と比べる（本院・在宅開始24か月未満の院は物差しから除く）。
- **到達目安に必要な新規** ＝ 到達目安 × 終了率。今の終了率のまま到達目安に届くのに要る月間新規。
- **横ばいの原因（A/B/C）**: 新規の強さが上位院の60%未満 → **B 新規が少ない**（紹介経路の課題）。終了率が比較院の中央値の1.2倍以上 → **C 終了が多い**（終了理由の内訳を確認）。どちらでもなく上位院比85%以上 → **A 担当エリアを取り切った**（エリアの再設定・隣接地域の開拓）。残りは B'（新規がやや少ない）。
- **データの扱い**: 移管・報告値の修正で減った人数は「終了」から差し引く（実際の看取り・入院等ではない）。終了は「新規 − 患者数の前月差」で求め、記入された終了と10人超ずれる月（一時的な数え直し）だけ記入値を使う。患者数の増減と（新規−終了）が3人超ずれる月は「突合」シートに一覧化。
- **限界**: 終了の理由（看取り・入院・転居・他院）と新規の紹介元が無いため、B院の弱い経路や、C院の終了が「質の高い看取り」か「他院への流出」かは区別できない。

## 3. 過去の指数を廃止・格下げした理由（まとめ）

1. **系統Aの手入力データの誤り**: 自治体57件中20件で人口・高齢者数が公式推計と10〜15%超乖離（入間市の人口が半分など）。A由来の努力指数・成果スコア・CM拠点比はすべて影響を受ける。
2. **院の座標の誤り**: 系統B/Cの院座標は概算で、本院は3.8km、三鷹は2.4km、所沢は1.3km、市川は1.2kmずれていた。国土地理院の住所検索結果に差し替えた。
3. **CM拠点あたり居宅数の誤読**: 系統Aは「ひばりが丘のCMあたり居宅は府中・調布の半分」としていたが、診療圏のCMには他のわかさ院のほうが近い事業所が多く含まれる。自院担当エリアに限ると、ひばりが丘は府中・調布と同水準（数値は機密版）。差の大半はグループ内重複による見かけ上のもの。
4. **機能強化型の判定漏れ**: 名簿の類型が全角数字（支援診１）のため、半角で判定すると全件「従来型」になる。修正済み（テストあり）。
5. **獲得率の地域バイアス**: 顕在需要は「すでに受けている人」なので、供給の少ない埼玉・千葉では分母が小さく、獲得率が過大に出る（本院・津田沼は都内院の約10倍に見える）。未充足度で補正した「実力」と、同条件の上位院と比べる「上位院比」に置き換えた。
6. **期待獲得率帯の根拠不足**: 稠密度4区分の閾値と調整係数が経験則で、実績との統計的検証がなかった。
